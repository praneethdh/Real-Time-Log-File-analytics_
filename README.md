# 🖥️ OS System Log Analysis using Hadoop MapReduce (Google Colab)

This project demonstrates **large-scale OS system log analysis** using **Apache Hadoop MapReduce** executed in a **Google Colab environment**.  
It processes **1 million synthetic system log entries** to analyze service-level activity using distributed computing concepts.

---

## 🚀 Project Overview

- Generates **1,000,000 OS system log records**
- Stores logs in **HDFS**
- Processes data using **Hadoop MapReduce (Java)**
- Analyzes system service usage frequency
- Visualizes results using **Python**
- Fully executed on **Google Colab**

---

## 🛠️ Technologies Used

- Apache Hadoop 3.3.6
- Java 8 (MapReduce)
- Google Colab (Linux runtime)
- HDFS
- Python
- Pandas & Matplotlib
